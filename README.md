# 🤖 Soham WhatsApp Business Bot

Personalized customer messaging bot powered by **Baileys** (WhatsApp) + **Groq AI** (Llama 3.3 70B).

Reads your customer Excel data, generates unique Hinglish messages for each customer using AI, and sends them with smart delays to avoid bans.

## Features

- ✅ One-time QR code scan to link WhatsApp Business
- ✅ Reads customer purchase history from Excel
- ✅ AI-generated personalized messages (Hinglish/Marathi)
- ✅ Smart delay queue (45-120s between messages)
- ✅ Session breaks to avoid spam detection
- ✅ Auto-reply to incoming messages in customer's language
- ✅ Typing simulation for natural feel
- ✅ Auto-reconnect on disconnection

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Environment
```bash
cp .env.example .env
```
Edit `.env` and add your **Groq API key** (free at [console.groq.com](https://console.groq.com)).

### 3. Place Excel File
Put your customer Excel file in the project root (or update `EXCEL_FILE_PATH` in `.env`).

### 4. Start the Bot
```bash
npm start
```

### 5. Scan QR Code
On first run, a QR code will appear in the terminal. Scan it with:
**WhatsApp → Settings → Linked Devices → Link a Device**

### 6. Use the Menu
After connecting, you'll see a menu:
- `1` → Start bulk campaign (generates AI messages for all customers)
- `2` → Send test message to yourself first
- `3` → Check queue progress
- `4` → Pause/Resume sending
- `5` → Stop campaign

## Deploy to Render (Free)

1. Push to GitHub
2. Go to [render.com](https://render.com) → New → Blueprint
3. Connect your repo → It will read `render.yaml` automatically
4. Add `GROQ_API_KEY` as environment variable
5. Deploy!

> ⚠️ For QR scanning on Render, you'll need to check the logs for the QR code on first deploy.

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `GROQ_API_KEY` | (required) | Your Groq API key |
| `EXCEL_FILE_PATH` | `Sale_Report_...xls` | Path to customer Excel |
| `MIN_DELAY_SEC` | `45` | Minimum delay between messages |
| `MAX_DELAY_SEC` | `120` | Maximum delay between messages |
| `MAX_MESSAGES_PER_SESSION` | `30` | Messages before taking a break |
| `SESSION_BREAK_MIN` | `20` | Break duration in minutes |
| `BUSINESS_NAME` | `Soham Electronics` | Used in AI prompts |
| `TEST_PHONE` | (optional) | Your number for testing |

## Anti-Ban Measures

- Random 45-120 second delays between messages
- Session breaks every 30 messages (20 min pause)
- Typing simulation (composing indicator)
- Each message is uniquely generated by AI
- Natural Hinglish tone (not templated)

## Tech Stack

- **Baileys** - Lightweight WhatsApp Web API (no browser needed)
- **Groq SDK** - Ultra-fast AI inference (Llama 3.3 70B)
- **xlsx** - Excel file parsing
- **Node.js 18+**
